# College Scorecard: What Predicts Graduate Earnings?

An empirical analysis of how institutional characteristics — selectivity, tuition, faculty resources, and student demographics — predict median earnings 10 years after enrollment, using U.S. Department of Education College Scorecard data.

---

```

├── data/
│   ├── college_scorecard_raw.csv       # Raw data (original download, do not modify)
```

## Setup (< 5 minutes)

### 1. Clone the repository
```bash
git clone <repo-url>
cd project
```

### 2. Create and activate the conda environment
```bash
conda env create -f environment.yml
conda activate ec34
```

### 3. Download the raw data
The raw data should already exist in this repo in the path data/college_scorecard_raw.csv. However, if it is not, you can download the College Scorecard institutional data from:
> https://collegescorecard.ed.gov/data/

Place the downloaded file at `data/college_scorecard_raw.csv`. (The cleaned version is already included in the repo, so you can skip to Step 4 if you just want to run the models.)

---

## How to Run (in order)

Run the three notebooks **in sequence**. Each notebook reads from `data/` and writes outputs to `output/`.

| Order | Notebook | What it does | Input | Output |
|-------|----------|-------------|-------|--------|
| 1 | `cleaning.ipynb` | Filters raw scorecard to 4-year operating schools; constructs SAT composite and tuition variables; labels institution type | `data/college_scorecard_raw.csv` | `data/college_scorecard_clean.csv` |
| 2 | `log_FE_model.ipynb` | Runs OLS and log-log regression of earnings on selectivity, tuition, Pell %, and institution type with state fixed effects; produces regression tables and scatter plots | `data/college_scorecard_clean.csv` | `output/tables/`, `output/figures/` |
| 3 | `lasso_randomforest.ipynb` | Runs LASSO (cross-validated) for variable selection; compares OLS vs. LASSO coefficients; uses Random Forest as a non-parametric robustness check; reports test-set RMSE across all models | `data/college_scorecard_clean.csv` | `output/figures/`, printed model comparison |

To run a notebook:
```bash
jupyter notebook code/cleaning.ipynb
```
Or open JupyterLab and run all cells top-to-bottom (`Kernel > Restart & Run All`).

## Data

**Source:** U.S. Department of Education, College Scorecard (most recent release)

**Sample:** Currently operating, 4-year degree-granting institutions with non-missing 10-year earnings data (~1,400–1,600 schools depending on release year).

**Key variables used:**

| Variable | Description |
|----------|-------------|
| `md_earn_10yr` | Median earnings of former students 10 years after enrollment (**outcome**) |
| `adm_rate` | Admission rate (proxy for selectivity) |
| `sat_composite` | SAT composite score (verbal + math midpoints, or reported average) |
| `tuition` | Out-of-state tuition for public schools; in-state for private |
| `pct_pell` | Share of undergraduates receiving Pell Grants (SES control) |
| `control` | Institution type: `public`, `private_np`, `private_fp` |
| `state` | State fixed effects (absorbs state-level labor market differences) |

## Models

Three models are estimated, all predicting (log) median earnings 10 years post-enrollment:

1. **OLS with state FEs** (`log_FE_model.ipynb`) — baseline linear regression with heteroskedasticity-robust (HC3) standard errors and state dummies.
2. **Log-log OLS with state FEs** (`log_FE_model.ipynb`) — log-transforms continuous predictors for elasticity interpretation; preferred specification.
3. **LASSO + Random Forest** (`lasso_randomforest.ipynb`) — uses a broader feature set (all available institutional characteristics) to check which variables OLS may have omitted, and benchmarks predictive performance.
